HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted nayae-website folder in VS Code.
3. Double-click index.html, or use your browser to open it.
4. Since this project uses multiple linked HTML pages, keep all HTML files, style.css and script.js together in the same folder.
